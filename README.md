# RISC-V Processor

## Overview
Design and implement a basic 32-bit RISC-V processor using Verilog, the SkyWater SKY130 PDK, and OpenROAD for ASIC design and physical implementation.

## Goals
- [ ] **Architecture:** Create a processor block diagram and datapath.
- [ ] **Verilog:** Implement basic RISC-V instructions and processor modules.
- [ ] **Verification:** Simulate and test processor functionality.
- [ ] **OpenROAD:** Run synthesis, floorplanning, placement, clock tree synthesis, and routing.
- [ ] **Optimization:** Revise Verilog to improve timing, area, and power.
- [ ] **Tapeout:** Generate a final GDSII layout.

## Tools
- **HDL:** Verilog
- **ISA:** RISC-V (RV32I)
- **PDK:** SkyWater SKY130
- **ASIC Flow:** OpenROAD Flow Scripts
